# AI Usage Policy

This project has strict rules for AI usage.
Contributors may utilize agents but should use them as needed, rather than as a first choice.

You will see the term "LLM", "Agent", and "AI" used interchangeably within this policy. 
They are all considered the same tool.

#### 1. All AI usage in any form must be disclosed.
You must state the tool you used (e.g. Claude Code, Cursor, Amp) along with
the extent that the work was AI-assisted. 
Please be as detailed as possible, continue reading below to understand what we expect.

#### 2. **The human contributor must fully understand all code.** 
If you can't explain what your changes do and how they interact with the
greater system without the aid of AI tools, do not contribute
those changes. For extra clarification, see below:
```
* You fully understand how to work with Minecraft 1.20.1 Forge OR 1.21.1 NeoForge code and are using the model purely for agility.
* You have knowledge of how GTCEu:Modern and relevant dependencies are structured and have gotten said knowledge without the use of an LLM summarization.
* You can independently verify, vouch, and explain in your own words what the code the model has produced does.
* You write the description of the Pull Request yourself, explaining what the change does, and why it's correct. 
* You disclose the use of an LLM/Agent in the Pull Request.
```
> [!WARNING]
> Using an LLM to write an ISSUE **OR** Pull Request will result in the issue or pull request being closed 
with a written warning as the close reason,
continued offenses will result in a repository wide ban.
#### 3. **No AI-generated media is allowed (art, images, videos, audio, etc.).**
Code the only acceptable AI-generated content, per the
other rules in this policy. Issues, Discussions, Pull Requests must all be human made.

#### 4. **Bad AI drivers will be blocked** 
People who produce bad contributions that are clearly AI (slop) may be blocked from making future contributions.
We love to help junior developers learn and grow, but if you're interested
in that, don't use AI and we'll help you. We're sorry that bad AI
drivers have ruined this for you.

#### 5. Do not be an Agent Proxy
Do not copy and paste a question into an agent and then paste/screenshot/yield that information in any way, without asking the other party involved first.

If both parties agree only then may you resort to an agent for assisting a discussion. 

Unprompted agent proxying does not give an impression of quality control, and turns away contributors who don't wish to engage with agents.
If someone wanted to utilize an agent there is a chance they would have done it themselves, or have asked.

Please upon doing so also be respectful with how you present an agent's output. Do not try to normalize or personify agents as they are not human.
> [!NOTE]
> This rule is special, as it applies to the Discord development chats as well. Breaking this rule will get you restricted from developer channels.


## Above all, remain respectful and kind to people
Please remember that this project is maintained by humans.

Every discussion, issue, and pull request is read and reviewed by
humans (and sometimes machines, too). It is a boundary point at which
people interact with each other and the work done. It is rude and
disrespectful to approach this boundary with low-effort, unqualified
work, since it puts the burden of validation on the maintainer.

In a perfect world, AI would produce high-quality, accurate work
every time and also not cause as many harms as it currently does.
For now this feels as the best compromise as to not outright ban these tools,
but to also not let them run rampant and create severe technical debt.
