# Introduction

GTCEu Modern has an extensible API that can be used by addon devs to create materials, recipes, new recipe types, and more complex things such as recipe conditions!

If you need help with something that isn't listed here, you can get help on the [Discord](https://discord.gg/bWSWuYvURP) too!

## Should I make an addon?

Making an addon requires you to know a fair amount of Java! If you're looking to do simpler things such as make or modify materials, items, recipes, machines, etc. you should look into our [KubeJS API](../Modpacks/index.md)

If you have an idea for an addon, like "better ME hatches", ask yourself if it should even be an addon first!

- Rockets -> Addon time!
- "Gregifying" recipes for other mods -> Addon time!
- Fixes to GT features -> Pull Request!
- Better UI elements -> Pull Request!
- More API interfaces -> Pull Request!
- Anything mod interoperability related -> Pull Request!

A lot of these will most likely be accepted into GTCEu Modern!

## So, how do I make an addon?

To begin, you will need to know Java to make an addon. There's no getting around this. A good starting point would be [MOOC](https://java-programming.mooc.fi/) or [W3Schools](https://www.w3schools.com/java/
)

When you're ready, start [here](./Setup.md)!
