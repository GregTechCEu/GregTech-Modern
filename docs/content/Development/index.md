# Developing GTCEu Modern

If you want to contribute to the development of GTCEu Modern, please feel free to submit a 
pull request with your changes.

The following pages describe a few important concepts that you will likely run into when working with our codebase.

Start with the [Codebase Guide](Codebase-Guide/index.md) if you are coming from the 1.20.1 branch, porting code from an
older branch, or trying to find the owner of a machine, recipe, UI, integration, registry, or generated data change.

!!! info "Local NeoForge Docs"

    A snapshot of the upstream NeoForged documentation is kept in this repository for porting reference. Check it before
    browsing for API answers so work stays aligned with the docs version used during this port. The snapshot lives in
    `docs/neoforged`; `docs/neoforged/GTCEU-UPSTREAM.md` records the upstream commit and snapshot date.
